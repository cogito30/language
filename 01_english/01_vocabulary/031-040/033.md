# Vocabulary(English)

1. comprehensive: 뚜렷한, 현저한
- a comprehensive checkup
- 종합 검진

2. considerate: 배려하는, 사려 깊은, 신중한
- considerate of others
- 다른 사람들을 배려하는

3. fortunate: 운 좋은
- be fortunate to
- ~해서 운이 좋다

4. sequential: 순차적인
- in sequential order
- 순차적으로

5. rigorous: 철저한, 엄격한
- a rigorous security check
- 철저한 보안 검사

6. candid: 솔직한, 자연스러운
- give a candid opinion
- 솔직한 의견을 주다

7. undisclosed: 밝혀지지 않은, 드러나지 않은
- donations from undisclosed sources
- 밝혀지지 않은 출처로부터의 기부

8. accidential: 우연한
- an accidential encounter
- 우연한 만남

9. unstable: 불안정한, 변하기 쉬운
- an unstable encounter
- 불안정한 상황

10. external: 외부의
- an external auditor
- 외부 회계 감사관
